# 블로그 글 넣는 법

이 폴더에 **JSON 파일 하나 = 글 하나**입니다. 파일을 떨구고 배포하면
목록 · 상세 페이지 · 사이트맵 · 구조화 데이터가 전부 따라옵니다.

## 파일 이름

```
2026-09-05-implant-life.json
```

- 앞의 날짜는 **정렬과 정리용**입니다. 주소에는 안 들어갑니다.
- 주소는 `/insight/blog/implant-life` 가 됩니다.
- ⚠️ **한 번 올린 글의 파일 이름을 바꾸지 마세요.** 그 주소가 404 가 되고,
  검색에 색인된 글이면 순위도 함께 사라집니다. 내용만 고치세요.

## 안에 들어가는 것

```json
{
  "title": "임플란트는 몇 년이나 쓰나요?",
  "date": "2026-09-05",
  "updated": "2026-09-11",
  "summary": "관리에 따라 크게 달라지는 이유를 정리했습니다. 목록과 검색 결과에 이 문장이 나갑니다.",
  "category": "임플란트",
  "html": "<p>첫 문단…</p><h2>무엇이 수명을 가르나</h2><p>…</p>"
}
```

| 칸 | 필수 | 설명 |
|---|---|---|
| `title` | ✅ | 글 제목. 검색 결과의 제목이 됩니다 |
| `date` | ✅ | 발행일 `YYYY-MM-DD` |
| `updated` | | 고친 날. 없으면 발행일과 같게 봅니다 |
| `summary` | ✅ | 한두 문장. 목록·검색 결과·SNS 미리보기에 나갑니다 |
| `category` | | 진료 영역 이름과 맞추면 목록에서 묶어 보기 좋습니다 |
| `html` | ✅ | 본문. 아래 참고 |
| `slug` | | 주소를 직접 정하고 싶을 때만. 없으면 파일 이름에서 뽑습니다 |
| `image` | | 대표 사진. `/img/blog/이름.webp` — 목록 카드·상세 머리·공유 미리보기에 나갑니다 |
| `imageAlt` | | 사진에 무엇이 찍혔는지. `image` 가 있으면 꼭 채웁니다 |

## 예약 발행

`date` 가 **오늘 이후**면 그 글은 그날 0시(한국 시간)까지 목록·상세·사이트맵 어디에도 안 실립니다.
날짜가 되면 저절로 실립니다(한 시간 안에). 그래서 열 편을 한 번에 넣고 날짜만 3일씩 띄워 두면
한 달에 걸쳐 자동으로 발행됩니다.

## 관리자 화면

`/admin` 에서 비밀번호로 들어가 글을 쓰고·고치고·삭제하고, 사진을 만들 수 있습니다.
'발행하기' 는 이 폴더에 파일을 **커밋**하는 것이고, 사이트에는 2~3분 뒤 반영됩니다.
서버에 `GITHUB_TOKEN`(과 사진용 `OPENAI_API_KEY`)이 있어야 하며, 없으면 화면에서 한 번 붙여 넣을 수 있습니다.

`title` · `date` · `summary` · `html` 중 **하나라도 비면 그 글은 안 실립니다**
(사이트가 깨지는 대신 조용히 건너뜁니다).

## 본문 HTML

쓸 수 있는 태그: `p` `h2` `h3` `ul` `ol` `li` `strong` `em` `a`
`blockquote` `figure` `img` `figcaption` `table` `th` `td`

- 클래스를 붙일 필요가 없습니다. 모양은 `globals.css` 의 `.blog-body` 가 정합니다.
- `h1` 은 쓰지 마세요 — 글 제목이 이미 `h1` 입니다. 소제목은 `h2` 부터입니다.
- `script` · `iframe` · `onclick` 같은 것은 자동으로 걷어냅니다.

## ⚠️ 올리기 전에 꼭

블로그 글도 **의료광고**입니다. 의료법 제56조가 그대로 적용됩니다.

- 치료경험담 · 후기 · 별점 ❌
- 치료 전후 사진 ❌
- '최고' · '유일' · '완벽' 같은 최상급 ❌
- 객관적 근거 없는 효과 단정 ❌

기계가 만든 글이라도 **사람이 한 번 읽고** 올리는 것이 맞습니다.
